Icons

The icons the live site uses: inline SVG interface icons that inherit the text colour (arrow, checkmark, external link, chevron, info, nav glyphs, social glyphs) and feature glyphs as image files inside two holders (white shapes in the blue circle, blue-gradient shapes in the grey square). Rules in foundation.md.

Interface icons the site uses (inline SVG, fill="currentColor", aria-hidden="true")

Every interface icon on the live site is an inline SVG embed that takes its colour from the text around it. The site stylesheets load no icon font (Material Symbols is not loaded; the AI pages outside the section set add it as page code). The Webflow components are Icon / Arrow (1,234 instances), Icon / Checkmark (50) and Icon / External link (32); the chevron, the info mark and the nav glyphs are embeds too.

Feature and product icons: image files from the Webflow CDN, inside a holder

Product and feature icons are not an icon set: they are SVG files in Webflow assets placed in one of two holders: white filled shapes in the v1 circle, blue-gradient filled shapes (#5c6ef8 to #1b89dc in the file, not tokens) in the v2 square. .card-icon-v1 is a 48px --social--main-blue circle (bordered cards, 14); .card-icon-v2 is a 72px #2b2b2b square with .5rem radius (icon cards, 13). The "Why social.plus" reasons (20) carry no glyph: their "icon" is a WebP tile image pinned to the bottom of the tile (TO CHECK).
