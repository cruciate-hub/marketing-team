FAQ

What is the difference between social.plus and Circle?

Circle is a community platform that gives you a branded site with discussions, events, courses and payments. social.plus is infrastructure you build into your own app: SDKs, fully customizable UIKit components and APIs for feeds, groups and forums, chat, live streaming, monetization and moderation. The core difference is where the experience lives. With Circle, your community is a separate destination. With social.plus, social and community features are embedded inside your product, under your brand.

What does social.plus offer that Circle doesn't?

social.plus gives your team native client SDKs for iOS, Android, TypeScript, Flutter and React Native, with fully customizable, white-label UIKit components across iOS, Android, Web (React), React Native and Flutter, so every social feature lives inside your app and matches your product's look and feel. social.plus also includes a commerce layer with product catalogues, product tagging across posts and live streams, and sponsored content placement for native ads in feeds, comments and stories. Short-form video clips and stories are built in. And your team gets comprehensive real-time analytics and insights with sentiment analysis and natural-language querying through Agentry, on data you fully own. Each social.plus application runs in the US, EU or Singapore region, chosen when you create it.

What does Circle offer that social.plus doesn't?

Circle offers built-in courses, paid memberships and subscriptions, email broadcasts and automations, a hosted website, workflows and gamification. social.plus does not offer these. With social.plus, billing, email and course delivery stay in the systems you already use, and private groups and forums, roles and user tags can control who sees what content.

Can I use just one part, or do I need the whole platform?

You can use the parts you need. social.plus is modular: you can start with chat alone, add feeds or groups and forums later, and expand into monetization or analytics when your product is ready. The documentation includes setup paths for specific use cases like direct messages, group chat and live chat. You can use the UIKit components or build your own interface on the SDKs and APIs. Circle bundles its features by pricing tier, with more capabilities available on higher plans.

Which platforms do the SDKs support?

social.plus has client SDKs for iOS (Swift), Android (Kotlin and Java), TypeScript/JavaScript and Flutter. React Native has its own package built on the TypeScript SDK, and the TypeScript SDK works with React, Next.js (client-side), Vue, Angular and Svelte. UIKit is available for iOS, Android, Web (React), React Native and Flutter, and server-to-server APIs cover administration, moderation and automation. Feature availability differs by platform, so check the Feature Matrix for specifics. Circle offers an Admin API and a Headless API with a server-side auth SDK, suited for teams extending the Circle platform rather than building a custom front end.

Who owns the data, and where is it stored?

You own the data your app generates through social.plus. Your app identifies each user with its own user ID, and social.plus recommends keeping credentials, email addresses and private profile data in your own system while social.plus stores social profile and moderation fields. Each application runs in the US, EU or Singapore region, chosen when you create it. A data export API delivers reports of recent data, and webhooks (in private beta) send events to your server. Circle hosts data in the US and offers member exports and API access for retrieving community content.

How does moderation compare?

social.plus includes user reports, a moderation feed in the Console for reviewing flagged content, blocklists and allowlists, PII detection, bans, mutes and custom roles. AI moderation covers images for pre-moderation and text, images and video for post-moderation, and live streams can be checked by AI while they run. Circle includes moderation tools across its plans, with AI-powered moderation available on higher tiers.

How would we move a community from Circle to social.plus?

Circle supports member exports and API access for community content. On social.plus, the server-to-server APIs handle data import and administration. Because your app supplies the user ID, user profiles attach to the accounts your users already have, so there is no separate account migration step. Talk to our team to plan a migration path.

What is Vise?

Vise is a local CLI and installable coding-agent skill that gives AI agents a repeatable workflow for social.plus SDK integrations. Developers using Claude Code, Cursor, Copilot, Codex, or VS Code install Vise, ask for a social.plus feature, and let Vise drive the loop. Vise clarifies the ask, offers product experience candidates, grounds the plan in current SDK facts, checks the implementation against 400+ platform-specific rules, and produces runtime evidence when requested. Vise runs on the developer's machine and never uploads source code, file contents, or queries.
