Icons

The icons the live site uses: inline SVG interface icons that inherit the text colour (arrow, checkmark, external link, chevron, info, nav glyphs, social glyphs) and white feature glyphs as image files inside two holders. Rules in foundation.md.

Interface icons the site uses (inline SVG, fill="currentColor", aria-hidden="true")

Every interface icon on the live site is an inline SVG embed that takes its colour from the text around it. There is no icon font (Material Symbols is not loaded). The Webflow components are Icon / Arrow (1,234 instances), Icon / Checkmark (50) and Icon / External link (32); the chevron, the info mark and the nav glyphs are embeds too.

Feature and product icons: image files from the Webflow CDN, inside a holder

Product and feature icons are not an icon set: they are SVG or WebP files in Webflow assets, white line glyphs, placed in one of two holders. .card-icon-v1 is a 48px --social--main-blue circle (bordered cards, 14); .card-icon-v2 is a 72px #2b2b2b square with .5rem radius (icon cards, 13). The "Why social.plus" blocks (20) and the industry pages use bare white WebP glyphs at about 40px.
