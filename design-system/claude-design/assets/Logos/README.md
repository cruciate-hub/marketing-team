The official brand logo files from the repository root (`assets/social-plus-logo.svg`, `assets/social-plus-icon.svg`), copied verbatim. For a website page use the `media` group instead: `66fe6169…_logo.svg` there is the full logo with the white wordmark, as the Nav and Footer show it, and it keeps its colours. Since 13.59 the files carry their colours on the shapes, so they keep them when uploaded.

- `social-plus-logo.svg`: the full logo, mark plus wordmark. The wordmark paths are #111 (`text--text-color-dark`), so this file is for light backgrounds (`main--white`, `main--whitesmoke`, `social--grey-background`); on dark backgrounds use the `media` logo, or set the wordmark to `fill="#ffffff"` (the inline SVG with that swap is in the Logo section of the brand book). The mark keeps its own gradients: artwork, not tokens.
- `social-plus-icon.svg`: the mark alone, for favicons, profile pictures, app icons and layouts too tight for the full logo. Works on dark and light backgrounds; never on `social--main-blue`.
- Clear space: the height of the mark on all four sides. Minimum size TO CHECK; do not go below the 2.5rem (40px) nav box. Never stretch, rotate, recolour, add a shadow or a glow.
- Not in the repository: the white and black mono sets (TO CHECK: Figma or the brand kit). Make them from the inline SVG by replacing every fill with #ffffff or #111111 until the files exist.
