The typography foundation of the social.plus website, rendered from `foundations/typography/preview.html` as the live site has it. The measured values, the rules and the known inconsistencies are in the "Typography" section of the brand book; the values themselves are tokens.

Heading sizes are fluid: `h1` `clamp(2.75rem, 1.5rem + 2svw, 5rem)` (44 to 80px), `h2` `clamp(2.25rem, 1.5rem + 2svw, 3.25rem)` (36 to 52px), `h3` `clamp(1.75rem, 1rem + 2svw, 2.25rem)` (28 to 36px), `h4` `clamp(1.5rem, .875rem + 2svw, 1.75rem)` (24 to 28px), `h5` 1.25rem (20px), `h6` 1.125rem (18px), as the site's variables `--_typography---h1-font-size` to `--_typography---h6-font-size` in `components/bundle.css`. The Heading sizes tokens (`h1-font-size` to `h6-font-size`) are the source of truth; the `h1` to `h6` type styles are specimens of them at 1440px, in rem. Use the token or the variable in CSS so headings scale.
