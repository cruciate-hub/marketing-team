Image ratios

The ratio classes of the style guide: .image-16-9, .image-2-1, .image-3-1, .image-4-3, .image-3-2 (max-width 100%, aspect-ratio, 16px radius; .image-4-3 has no radius). Pages mostly use .image-square_radius, .image-fw-radius and .image-3-2. The style guide shows Webflow placeholders; here each class gets one site image (the gaming industry hero cover) so the ratio and radius are visible.
