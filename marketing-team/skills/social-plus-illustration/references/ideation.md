# Ideation: diverge, then converge

Similar visuals come from similar first ideas. This step forces breadth before any choice: generate many ideas through different lenses, pair them with compositions, then pick the most different strong ones. Do it in chat, compactly; the person sees the long list and the pick.

## 1. Pin down the post (2 lines)

- **Claim**: the point the visual must make, in one sentence (a post's argument, a feature's benefit, a campaign message).
- **Named subjects**: companies and technologies the content is about (their logos will be in the image — `third-party-logos.md`).
- **Audience**: who reads it and what they'd instantly recognise (developers: a TODO, a stack trace; product leaders: a metric, a roadmap; community managers: a report queue).

## 2. Diverge: 10 raw ideas through 8 lenses

Write one short line per idea. Use every lens at least once; the lens is what makes ideas differ in kind, not just in detail.

| Lens | Question | Example ("What AI coding agents leave out…") |
|---|---|---|
| **Metaphor** | What everyday thing behaves like this? | an iceberg of features; a stage set — façade only |
| **Consequence** | What happens to a user because of it? | spam slips into a thread nobody can report |
| **The moment** | What single instant captures it? | the agent's "Done ✓" right before launch |
| **The artifact** | What real object from the work says it? | a `// TODO: moderation` left in the code |
| **The person** | Whose face or name tells it? | a moderator with an empty tool panel |
| **Scale** | What happens at 10× or 1,000,000×? | the feed at launch day volume, buckling |
| **Before / after** | What changes, side by side? | agent build vs production-ready, same post |
| **Absence** | What's missing, and how do you draw nothing? | empty slots in a grid of features |

Rules for this list:
- **Kill the first idea.** Write it down, then mark it "first idea". It may still win later, but it can't be the default.
- **No two ideas may share both lens and focal object.**
- Go for at least two ideas that feel slightly too strange. They're often the distinctive ones after a little taming.

## 3. Pair with compositions

For each idea worth keeping (aim for 5–6), name the archetype from `composition-library.md` that would show it best and the focal object. One idea can try two archetypes. Note which archetypes and focal objects recent visuals for the same surface used, and cross those pairings out.

## 4. Converge: score and pick

Score each surviving pairing quickly, 1–3, on:
- **Clear**: would someone get the point at the smallest size it will be shown, without the surrounding text?
- **Distinct**: does it look unlike the recent thumbnails and unlike the other candidates?
- **True**: does it only show things social.plus or the post actually stand behind (no invented numbers, no fake product claims)?
- **Audience**: will the reader recognise it immediately?

Pick 2 concepts (3 if the scores are close) that maximise difference: **different lens, different archetype, different focal object, accent in a different region**. If both picks came from the same lens, swap the weaker one for the best idea from another lens.

## 5. Present

In chat, a compact table of the 10 ideas (lens · idea · archetype), the crossed-out pairings with the reason ("used last post"), and then the 2 picks written as concept briefs (Idea, Archetype, Objects, Words, Blue). Then build.

## Worked example (compressed)

"What AI coding agents leave out when they build in-app social features from scratch". Recent: wall + focal object (push post).

1. Absence · empty slots in a feature grid · isometric grid — *first idea*
2. Moment · agent cursor selecting only the visible feed · selection overlay
3. Consequence · spam in a thread, nothing to stop it · device crop
4. Artifact · `// TODO: moderation` in generated files · type-led field
5. Metaphor · façade: a feed card propped up by struts from behind · stack, seen at an angle
6. Scale · one comment box multiplied into a buckling stack · stack
7. Person · moderator with an empty review queue · macro detail
8. Before/after · same post, split: agent build vs production · split frame
9. Moment · terminal "Done ✓" in huge mono with a blinking blue caret on the next line · macro detail
10. Absence · a toggle labelled "Moderation" that isn't wired to anything · macro detail

Picked: 4 (artifact, type-led field) and 3 (consequence, device crop) — different lens, archetype, object and accent position; 2 and 1 kept as alternates.
