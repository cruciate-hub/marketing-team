The typography foundation of the social.plus website. Its card is not on this page since 9 October 2026: the token views show the same values. The preview stays in the repository (`design-system/foundations/typography/preview.html`). The measured values, the rules and the known inconsistencies are in the "Typography" section of the brand book; the values themselves are tokens.

The live site's heading sizes are fluid: `h1` `clamp(2.75rem, 1.5rem + 2svw, 5rem)` (44 to 80px), `h2` `clamp(2.25rem, 1.5rem + 2svw, 3.25rem)` (36 to 52px), `h3` `clamp(1.75rem, 1rem + 2svw, 2.25rem)` (28 to 36px), `h4` `clamp(1.5rem, .875rem + 2svw, 1.75rem)` (24 to 28px), `h5` 1.25rem (20px), `h6` 1.125rem (18px), as the site's variables `--_typography---h1-font-size` to `--_typography---h6-font-size` in `components/bundle.css`. These are the live sizes the captured sections render with; new work uses the web library's type scale (the Type scale tokens `fluid-display` to `fluid-h4`, decision 8 October 2026), as the Typography section says.
