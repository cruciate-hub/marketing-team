# Email Response Templates

Tone: Polite, constructive, strict with guidelines. Works for email or LinkedIn.

## Formatting Rules (apply to every draft)

These are hard rules. A draft that breaks them is not ready to send.

1. **Never hard-wrap a paragraph.** Each paragraph is one single unbroken line, no matter how long. Manual line breaks look fine in a terminal but turn into ragged mid-sentence enters the moment the text is pasted into LinkedIn or an email client.
2. **One blank line between paragraphs. Never two.**
3. **Never use em-dashes (—) or en-dashes (–) as punctuation.** Use a comma, a colon, or split the sentence. This applies to every draft and to any commentary around it.
4. **Keep it to 3-5 short paragraphs.** Greeting, verdict, reason, next step, sign-off.
5. **No bullet lists unless there are 3+ genuinely separate issues.** Prose reads better in a LinkedIn DM. When bullets are unavoidable, keep each one on a single line.

## Approval (Score 8-10)

```
Hi [Name],

Thanks for sending this over. I've reviewed your proposal against our guidelines and it looks good to go.

[If any minor notes, add here as one flowing sentence]

I'll get this live shortly and send you confirmation once it's published.

Best,
Stefan
```

## Revision Request (Score 5-7)

```
Hi [Name],

Thanks for the proposal. I've reviewed it against our guidelines and it's close, but I need a couple of things adjusted before I can place it.

[Issue 1 and the fix, in one flowing sentence.]

[Issue 2 and the fix, in one flowing sentence.]

Happy to proceed as soon as those are sorted. Just send the revised version over.

Best,
Stefan
```

### Common Revision Requests

Drop these in as a paragraph. Each one is a single unbroken line.

**Anchor too long or competitive:**
```
The anchor "[anchor]" is a bit too keyword-heavy for us, so could you shorten it or suggest something that reads more naturally in context? We're looking for anchors that fit the sentence rather than target a specific search term.
```

**Placement in intro/conclusion:**
```
We don't place links in introductions or conclusions, so could you suggest a spot in the body of the article where it sits more naturally with the surrounding content?
```

**Text doesn't match tone:**
```
The proposed text doesn't quite match the article's tone. This piece is [casual/formal/technical], so could you revise it to sit closer to that style?
```

**AI-sounding phrases:**
```
The text reads a little AI-generated, particularly "[specific phrase]". We need copy that's fully human-written and matches our house style, so could you rework it?
```

**Off-topic modification:**
```
The proposed text doesn't align with this section. That paragraph is about [topic], so the addition needs to connect directly to it. Could you propose something more contextually relevant?
```

**Target page competes with article:**
```
The target page competes with our article's keywords, and we can't link out to content targeting the same terms we're ranking for. Do you have an alternative page that's complementary rather than competitive?
```

## Rejection (Score 1-4)

```
Hi [Name],

Thanks for reaching out. Unfortunately this one doesn't work for us.

[Primary reason, in one flowing sentence.]

That's a firm guideline on our end, so I'm not able to make an exception here.

If you'd like to pick a different article from our blog, I'm happy to take a look. Just send over the URL and the proposed placement.

Best,
Stefan
```

### Common Rejection Reasons

**Excluded article:**
```
That article isn't available for link exchanges. It's on our excluded list for strategic reasons, so I can't make edits to it.
```

**Restricted category:**
```
We don't accept links from [category] sites. That's a firm policy on our end.
```

**DR too low:**
```
The target domain's DR sits below our minimum of 50, and we need DR 50+ for every link exchange.
```

**Wrong page type:**
```
We only link out to blogs, articles and glossaries, so [homepages/product pages/landing pages/service pages] don't qualify.
```

**Location-specific or niche page:**
```
We don't link to location-specific pages or highly niche industry content, as those don't align with our blog's broader audience.
```

## Follow-Up (No Response)

```
Hi [Name],

Just following up on the link exchange proposal from [date]. Let me know if you'd like to proceed, or if you have any questions about the feedback.

Best,
Stefan
```
